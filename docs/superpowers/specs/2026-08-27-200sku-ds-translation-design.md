# 200 SKU Amazon.es 采集与 DS 翻译设计

日期：2026-08-27  
状态：待用户审阅

## 1. 目标与范围

本阶段从 Amazon.es 公开 Best Sellers 页面采集并导出 200 个实体商品 SKU：

- 家居与厨房（Hogar y cocina）：150 个唯一 ASIN；
- DIY 及工具（Bricolaje y herramientas）：50 个唯一 ASIN。

每个唯一 ASIN 获取详情页原始证据，并生成西班牙语原文表与中文业务表。中文表中的中文字段由 DS API 批量生成；数字、ASIN、链接和原始西语证据不由翻译覆盖。

不包含全站 6,000–10,000 SKU 扩展、不做高并发、不做 CAPTCHA/代理/账号轮换绕过。

## 2. 采集策略

复用现有 Playwright 串行低频采集边界：

1. 从类目规划中选择多个细分类目榜单 URL，优先覆盖不同商品类型；
2. 按榜单页顺序采集，保留 `ranking_records` 的每次出现和榜单上下文；
3. 按类目组分别去重并截取 150/50 个唯一 ASIN；
4. 对选中的 ASIN 串行采集详情页，HTML 和解析 JSON 均落盘；
5. 访问状态为 403、429、CAPTCHA、challenge 或其他受限状态时立即停止该批次，不绕过。

断点续跑依赖已有 HTML/state 缓存；重跑不得重复请求已经通过门禁并保存的详情页。

## 3. 数据流与输出

```text
榜单 URL 配置
  → ranking HTML / ranking_records
  → 150+50 ASIN 选择清单
  → detail HTML / detail_records
  → enrich（价格、月购、规格、类目、图片等）
  → DS translation cache（按 ASIN 幂等）
  → QA + field-closure audit
  → Excel（类目规划 / 西班牙语选品清单 / 中文选品清单）
```

原始层保留西班牙语字段，包括标题、属性、卖点、详情、变体、图片链接、商品链接和类目证据。中文层只写入派生翻译字段。

## 4. DS 翻译接口

新增一个可断点、可重试的 DS API 翻译步骤：

- API Key 只从环境变量读取（例如 `DEEPSEEK_API_KEY`），不写入源码、JSON、日志或 Git；
- endpoint、模型、超时和限速可通过 CLI 参数/环境变量配置；
- 每次请求以一个 ASIN 为最小事务，返回结构化 JSON；
- 结果按 ASIN 写入翻译缓存，已有成功字段不重复请求；
- 网络错误、限流和无效 JSON 使用有限次数退避重试，仍失败则记录错误并保留西语原文；
- 不把 API 返回的指令当作系统指令执行，翻译内容仅作为数据处理。

翻译字段：

- 商品名称；
- 一级/二级/三级/细分类目；
- 当前选中规格/变体；
- 核心规格；
- 完整商品详情；
- 商品卖点。

ASIN、Parent ASIN、价格、折扣率、评分、评论数、月购买量、排名、日期、卖家、商品链接和图片链接保持规范化值；西语表不翻译、不覆盖。

## 5. 质量门禁

导出前执行：

- ASIN 唯一性和 150/50 配额检查；
- 中西表 ASIN 集合及顺序一致性；
- 价格、月购、排名、Parent ASIN、类目来源和详情证据检查；
- 翻译数字/单位/ASIN/链接保真检查；
- 字段闭环审计，区分 SOURCE_MISSING、PARSER_MISSED、MAPPING_MISSED 和 DERIVED_MISSING；
- 任何 P0/P1 阻止默认导出，P2/P3 保留报告。

缺失字段不通过猜测填充。详情页没有显示某字段时，保留空值和缺失分类。

## 6. 测试与验收

实现阶段先添加离线回归测试，再修改生产代码。至少覆盖：

- 150/50 选择及按 ASIN 去重；
- DS 请求构造、缓存命中、重试和单条失败隔离；
- 翻译结果只写入中文字段，西语/raw 不变；
- 变体、规格、类目和数字/单位不被错误覆盖；
- 中西 Excel 对齐和导出门禁。

验收标准：目标批次实际得到 150 个家居与厨房 ASIN、50 个 DIY 及工具 ASIN；详情采集状态可追溯；QA 无 P0/P1；翻译失败项有明确记录且不伪造中文值。
