# 全量离线复核：异常输入、缓存状态与人工备注

基线：`a7bfa9aa`。本轮为快照模块下一阶段开发前的程序复核，不启动采集、真实翻译、数据迁移或历史回填。

## 已复现并修复的边界

| 编号 | 缺陷与触发方式 | 修复及验证 |
|---|---|---|
| F01 | DetailState 为空时，旧 details.json 读失败或格式错误被忽略，随后可能被空数组覆盖 | 旧清单必须成功读取且为合法 ASIN 记录列表；共享锁走现有有限重试；持久错误在请求和写入前抛出。保留原文件、未知原始字段及人工备注 |
| F02 | 旧 VALID_PRODUCT_PAGE 标记优先于较新的访问限制、解析失败、网络失败或无效状态 | 负向证据优先；planner 与 executor 复用同一缓存分类。已恢复的 initial CHALLENGE + final NORMAL 不被当成新拦截；历史验证码缓存规则不变 |
| F03 | 导出只读取第一张有备注的表，漏掉另一张表的其他商品备注 | 汇总全部含 ASIN/备注列的表，按 ASIN 回填并保留文本格式。当前记录已有备注继续优先；待回填的同 ASIN 存在不同备注时报 MANUAL_NOTES_CONFLICT，原交付文件不覆盖，不猜选 |
| F04 | 详情计划接受重复 ASIN，且非对象行被过滤后仍可能通过 hash 校验；无头计划可混入多个 snapshot_id | 写计划和执行前校验完整行集合、合法 ASIN、去重及 snapshot_id 一致性。错误输入不能缩小任务分母或改写旧计划 |
| F05 | 直接调用详情采集不先校验/规范 ASIN，大小写和空白可造成额外请求；空输入仍进入配送及输出路径 | 在配送检查或文件写入前校验身份、规范大小写并稳定去重；非法输入报错，空输入无副作用。有效身份的配送和访问门禁保留 |
| F06 | candidate_ids=[] 被当成未筛选，实际选择全部候选 | 只有 None 表示默认选择；显式空集合保持空，不自动扩大范围 |
| F07 | 通用 evaluate_research_readiness 在空检查、缺少状态/名称、ERROR 或 SKIPPED 状态下可返回 RESEARCH_READY | 空结果为 PARTIAL_REVIEW；结构或状态未知为 BLOCKED；不把缺省值当 PASS。正式 quality-audit 仍要求原八项检查，WARN/REVIEW/BLOCK 的既有语义不变 |

F01—F05 属于数据保留、任务计数或身份边界缺陷。F06 为选择范围缺陷。F07 是通用接口的失败开放问题；不能据此推断已运行的正式八项审查曾被空输入绕过。

## 快照模块后续边界

本轮没有扩展快照架构或启用实验执行器。当前20,000候选及喜爱榜最低3,000是既有任务配置约束；不把它当成通用模块的永久容量上限。候选分组数量仍不同于已核验可售SKU数量。
